# Legacy and unverified configs

Files under `unverified/` were retained from the earlier archive but referenced
missing base configs or a different SAE feature dictionary. They are not part of
the new AmbiK v1 workflow and should not be run without reconstructing their
original environment.

Known valid historical single-feature lists are under `configs/steering/` and
ClarQ task-0 configs are under `configs/clarq/`.
